Sistema de dirección

El sistema de dirección de un vehículo sirve para orientar las ruedas y permitir que el conductor controle la trayectoria del automóvil. Gracias a este sistema, el vehículo puede girar, cambiar de dirección y mantenerse estable durante la conducción.

Además, ayuda a que las maniobras sean más seguras y precisas, reduciendo el esfuerzo del conductor mediante mecanismos como la dirección asistida.

Entre sus componentes principales se encuentran:

  1. Volante
  2. Columna de dirección
  3. Las juntas universales
  4. La cremallera
  5. Las bieletas
  6. Las rótulas
